信用評価損益率（二市場）

出所）東京証券取引所、名古屋証券取引所。2007年1月〜2026年9月18日は週足、2026年9月25日以降は日足。

算出式

  • 評価損益率（買い方）＝（買残の時価 − 買残の約定代金）÷ 買残の約定代金．時価は、銘柄毎の買い残株数に終値を掛け、全銘柄を合計したもの。
  • 市場で広く用いられている日経・QUICKの評価損益率とは、算出方法が異なることにより、値が異なる。
  • QUICK公表値（参考）の評価損益率＝[買残高金額－｛（貸借融資金額＋自己融資金額）／（貸借融資株数＋自己融資株数）×社内対当株数＋貸借融資金額＋自己融資金額｝]／買残高金額×100（QUICKの算出要綱）。
  • 信用倍率（約定代金）＝買残高 ÷ 売残高．東証・名証公表の銘柄別信用取引残高（申込み現在）による。
  • 株価は、東証・名証の日報による。出来ずは直近の終値で評価する。また、株価がなく評価しない銘柄がわずかに存在する。
  • 週次の推移（2007年〜2026年8月）は、同様の方法で算出した。
  • 本ページの値は参考値である。免責についてはフッター記載のとおり。
  • 算出方法の詳細、2007年以降の長期の推移の分析、およびQUICK公表値との比較については、現在、論文を準備中である。
